完整创作流程：
1. Ideation - 创意生成（3-6×200字）
2. Synopsis - 一页提要（锚点，≤1000字）
3. Characters - 角色设计
4. Theme - 主题开发
5. Structure - 结构节拍
6. Scenes - 场景规划
7. Set Pieces - 关键场面设计
8. Dialogue - 对白创作
9. Symbolism - 象征与暗线
10. Pacing - 节奏控制
11. Endings - 结局设计
12. Rewrite - 重写迭代

**关键原则：Step 2 是锚点，任何变更需先更新此步**

## 创作规律总结

### 网文字数分配（1.5-2万字短篇）
- 开篇：15-20%（2,250-4,000字）
- 发展：35-45%（5,250-9,000字）
- 高潮：25-35%（3,750-7,000字）
- 结局：10-15%（1,500-3,000字）

### 冲突密度控制
- 每500-1,000字：小节拍
- 每2,000-3,000字：中转折
- 每5,000-6,000字：大冲突

### 反转设计公式
```
预期建立 + 信息隐藏 + 线索埋设 + 瞬间揭露 = 完美反转
```

### 冲突设计公式
```
目标 + 障碍 + 后果 = 冲突
```

### 场景五要素
```
场景 = 目标 + 冲突 + 转折 + 变化 + 钩子
```

## 创作技巧速查

### 开篇技巧
- **危机式开场**：主角立即陷入困境
- **悬念式开场**：反常现象引发好奇
- **对比式开场**：现状与理想的落差
- **日常式开场**：平静生活被打破（不要过长）

### 悬念维持
- **信息差**：读者知道 vs 角色知道
- **反常现象**：不合理的事情发生
- **时间限制**：倒计时压力
- **多线并进**：多条线索展开

### 反转增强
- **红鲱鱼**：错误线索强化预期
- **合理暗示**：线索回头看合理
- **多层反转**：真相背后还有真相
- **情感冲击**：反转有强烈后果

### 情感营造
- **感官细节**：具体可感的描写
- **内心独白**：真实可信的内心活动
- **情感层次**：复杂变化，不是单一情绪
- **环境烘托**：用环境反映情感

### 对话技巧
- **潜台词丰富**：表层意思 + 潜台词 + 情绪
- **声音独特**：每人物有独特说话方式
- **动作配合**：对话时结合动作
- **推动情节**：不是闲聊，要有用
- **沉默张力**：不说话的时刻

## 故事结构模板

### 三幕式结构
- **Act I（Setup）**: 开篇 → 激励事件 → 第一转折点
- **Act II（Confrontation）**: 承诺与计划 → 中点反转 → 升级 → 至暗时刻
- **Act III（Resolution）**: 最终选择 → 新平衡

### 15拍结构（Save the Cat）
Opening Image → Setup → Catalyst → Debate → Break into Two → B Story → Fun & Games → Midpoint → Bad Guys Close In → All Is Lost → Dark Night → Break into Three → Finale → Final Image

### 8序列结构
8个序列：Setup → Launch → Rise → Midpoint → Complications → Fall → Climax → Resolution

## 人物塑造

### 三层人物模型
1. **表象层** - 外貌、身份、社会地位、语言风格
2. **内在层** - 核心欲望、深层恐惧、价值观、道德标准
3. **冲突层** - 表象vs真实、欲望vs恐惧、理想vs现实

### 缺陷-成长弧光
- **初始** - 缺陷主导，造成问题
- **尝试** - 意识到缺陷，试图克服但失败
- **至暗** - 缺陷造成最大伤害
- **转折** - 关键事件触发，做出不同选择
- **最终** - 缺陷转化，获得成功

## 男频网文创作核心方法论

### 四步创作法

**第一步：一句话概括故事**
```
负价值形容词的×主角身份×想要×正价值欲望×而去×动作的故事
```
示例：废柴的天才想要出人头地而去成为斗帝的故事
要点：正负价值对立、欲望具象化、设置期待感

**第二步：构建故事支点**
1. **人物支点** - 正向期待 + 负价值冲突（如：师者+离经叛道）
2. **世界观支点** - 新规则与价值观冲突（如：必须吃早餐才能存活）
3. **金手指支点** - 原是工具，主角驱动金手指（如：想赚钱+亏钱系统）
4. **悬念支点** - 系统性制造悬念，必须圆回来
5. **二次行为** - 过激行为引发后续事件
6. **激励事件** - 打破局面迫使选择

**第三步：切入事件（开篇七要素）**
1. 展示主角处境和对现状的不满
2. 给读者喜欢主人公的理由
3. 主人公遭受不公平的伤害
4. 主人公面临危险或已身处危险
5. 金手指出现，事情出现转机
6. 建立短期追求的目标
7. 一个引人致胜的情节钩子

**第四步：大纲结构（三幕式 + 节拍器）**
- 长时间线：三幕式主要脉络（建制→对抗→结束）
- 短时间线：情绪拉扯（期待→满足→期待）
- 首卷建议：15-20万字，高潮放10万字后

### 脑洞文四大分类

**都市脑洞：**
- 神豪/直播/文娱/美食/宠物/校花类
- 金手指：系统/异能/身体异变
- 节奏：快、爽

**玄幻脑洞：**
- 无敌签到/万倍返还/长生苟道/宗门建设/收徒变强
- 成熟套路吃透 + 创新变种

**悬疑脑洞：**
- 惊悚游戏/规则怪谈/诡异复苏/恐怖末世
- 重点：金手指新颖性 + 逻辑严密

**科幻：**
- 末世/黑科技/星际
- 重点：科技想象 + 力量体系 + 人性变化

### 男频专门技巧

**理解爽点：** 满足情绪需求 ≠ 装逼打脸
**情绪曲线：** 曲线起伏 = 冲突剧烈 = 情绪波动
**反同质化：** 不同期待类型，给读者新鲜感
**书名技巧：** ≤15字、设置期待、筛选读者
