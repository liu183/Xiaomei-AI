# 番茄末世文创作技能

## 技能简介

基于AI自动生成系统的番茄平台末世爽文创作方法论，专门针对囤货、基地建设、多女主修罗场等核心元素的批量生产技能。

---

## 一、核心原理

### 番茄末世文公式

```
番茄末世文 = 末世危机 + 系统金手指 + 囤货爽点 + 危机解决 + 悬念钩子
```

### 关键爽点类型

1. **囤货爽点**：物资获取、空间展示、装逼
2. **危机爽点**：绝境翻盘、反杀碾压、扮猪吃虎
3. **修罗场爽点**：女主争宠、情感冲突、暧昧氛围
4. **升级爽点**：技能解锁、基地升级、实力突破
5. **打脸爽点**：反派挑衅、主角反击、众人震惊

## 二、创作技能模块

### 技能1：世界状态构建（World-Building）

#### 末世世界必填要素

```
【末世类型】
- 天灾害：丧尸、病毒、自然灾害
- 人灾害：核爆、异能失控、维度入侵

【文明状态】
- 崩溃时间：[立即/三天后/一个月后]
- 存活比例：[10%/30%/50%]
- 政府状态：[完全崩溃/避难所存在/军政府接管]

【势力分布】
- 幸存者小组：[规模/实力/资源]
- 掠夺者帮派：[领地/手段/目标]
- 官方基地：[等级/进入条件/规则]
- 特殊势力：[异能组织/科技势力/变种生物]

【资源系统】
- 稀缺资源：水/电/食物/药品/燃料
- 珍贵资源：金条/钻石/电子设备/武器
- 武器分级：冷兵器/枪械/重型武器/未来武器

【变异体系】
- 变异生物：普通/精英/领主/神级
- 人类变异者：觉醒率/能力类型/等级划分
- 特殊存在：变异兽王/古老文明/系统宿主
```

#### 番茄末世世界观模板

```
末世类型：血雾变异
崩溃时间：三天后
存活比例：5%

主要势力：
- 幸存者：零散小组，装备简陋
- 掠夺者：黑帮转型，武器精良
- 官方基地：A级避难所，严格管理
- 系统宿主：极少数觉醒者

核心矛盾：资源争夺 + 生存竞争 + 人性考验
```

### 技能2：角色状态设定（Character-Setting）

#### 主角人设模板

```
【身份背景】
- 前身身份：兵王/特种兵/雇佣兵/普通学生/科研人员
- 末世优势：[军事技能/生存经验/专业知识/人脉关系]
- 初始装备：[武器/物资/基地/情报]

【系统金手指】（必须符合系统文规则）
- 签到型：每日签到/连续签到/地点签到
- 囤货型：无限空间/物资刷新/自动补充
- 成长型：技能升级/属性加点/任务奖励
- 禁忌：不能无限制复活/修改人生/直接成神

【性格特征】
- 表面性格：咸鱼/冷血/腹黑/幽默
- 内心性格：护短/复仇/隐忍/正义
- 行为准则：[底线设定/原则雷区/触发条件]

【能力体系】
- 初始能力：[身体素质/特殊技能/装备加成]
- 成长路径：[等级提升/技能解锁/装备升级]
- 爆发条件：[极限触发/情感爆发/系统加成]
```

#### 女主人设模板（双女主配置）

```
女主1（战斗型/魅惑型）：
身份：快穿者/特种兵/杀手/特工
性格：高冷/腹黑/妖娆/杀伐果断
能力：超凡战力/特殊技能/系统辅助
定位：主力输出/侦查情报/战略谋划

女主2（养成型/依赖型）：
身份：豪门千金/校花/医生/科研人员
性格：温柔/单纯/坚韧/依赖性强
能力：资源管理/医疗救治/科研知识
定位：后勤保障/团队核心/情感羁绊
```

#### 配角人设（必须功能性）

```
功能型配角：
- 军方联系人：提供官方线、发布任务
- 信息贩子：情报交易、资源置换
- 背叛者：制造冲突、推进剧情
- 领路人：引导主角、传授经验
```

### 技能3：爽点调度系统（Shuang-Point-Scheduling）

#### 爽点密度控制

```
每章爽点要求：
- 小爽点：2-3个（每800字一个）
- 中爽点：每3章1个
- 大爽点：每10章1个
- 超大爽点：每卷1个
```

#### 爽点库（番茄末世文专用）

**A类：囤货爽点**
```
1. 系统签到获得高级物资
2. 空间展示惊艳众人
3. 扔出珍贵物资打脸反派
4. 清空超市/军火库/仓库
5. 物资分享获得威望升级
```

**B类：危机爽点**
```
1. 丧尸潮中淡定反杀
2. 掠夺者来袭被碾压
3. 绝境中开启系统新功能
4. 轻松解决精英/领主变异体
5. 剧毒环境安然无恙
```

**C类：修罗场爽点**
```
1. 女主同时吃醋
2. 女主为了争宠展现实力
3. 主角被女主团宠待遇
4. 其他男主/配角嫉妒不已
5. 女主主动投怀送抱
```

**D类：打脸爽点**
```
1. 反派嘲讽后被秒杀
2. 质疑主角实力的被打脸
3. 小人算计被主角识破
4. 看不起主角的后悔莫及
5. 主角身份/实力揭晓
```

**E类：系统爽点**
```
1. 连续签到获得大奖
2. 完成特殊任务升级
3. 解锁新功能/新技能
4. 系统智能度提升
5. 发现系统隐藏功能
```

### 技能4：单章剧情生成（Chapter-Generation）

#### 番茄末世文章节公式

```
单章结构 = 开场钩子 + 冲突升级 + 爽点爆发 + 悬念结尾

具体分配：
- 开场钩子（200字）：快速切入、制造悬念
- 冲突升级（800字）：矛盾展开、危机降临
- 爽点爆发（800字）：高潮时刻、情绪释放
- 悬念结尾（200字）：留下钩子、吸引阅读
```

#### 章节生成Prompt模板

```
你是一名番茄平台末世系统文作家。

请根据以下设定写一章末世爽文（2000字）：

【世界背景】
末世类型：血雾变异
当前时间：第7天
地点：幸存者小区

【人物状态】
主角：陆沉（兵王+咸鱼签到系统）
当前实力：B级进化者
当前资源：地下室基地、无人机军团、充足物资
女主1：苏媚（快穿者，高冷魅惑）
女主2：林若雪（豪门千金，单纯依赖）

【本章冲突】
掠夺者帮派"黑狼团"准备袭击小区，觊觎女主林若雪和主角物资

【本章爽点要求】
必须包含：
1. 囤货爽点：展示空间/物资实力
2. 战斗爽点：碾压入侵者
3. 修罗场爽点：女主苏媚对主角的态度变化

【写作风格】
节奏快、对白多、爽点密集、每行字都有钩子

【结尾要求】
留下悬念：有人发现了主角的秘密/新的危机逼近

请写出完整章节。
```

### 技能5：长线剧情推进（Long-Term-Plot）

#### 10章剧情规划模板

```
【当前阶段】
基地初建期（第1-40章）

【当前状态】
主角签到10天，获得基础技能和物资，建立地下基地
双女主已登场，感情线萌芽
周围幸存者开始聚集

【未来10章规划】

第1-3章：基地防御战（小高潮1）
- 冲突：掠夺者第一次小规模袭击
- 升级：主角展示部分实力
- 爽点：无人机碾压、签约威慑
- 悬念：掠夺者首领注意到主角

第4-6章：资源搜集（过渡）
- 任务：前往废弃城市场馆
- 危机：变异生物+散兵游勇
- 爽点：清空商场、女主1展现实力
- 修罗场：女主2吃醋

第7-9章：军方的邀请（冲突升级）
- 冲突：基地暴露，军方派人接触
- 选择：拒绝加入但保持合作
- 爽点：主角装逼、军方重视
- 悬念：军方内部有人针对主角

第10章：系统升级（大高潮）
- 触发：连续签到10天奖励
- 获得：新功能【特殊地点签到】
- 任务：第一特殊地点【医院停尸房】
- 悬念：系统秘密初现端倪
```

#### 卷级结构（50章一卷）

```
【第一卷：末世降临与基地初建】（1-50章）

- 开篇（1-10章）：
  - 末世降临+系统激活
  - 签到囤货+初遇女主
  - 第一次危机+打脸爽点

- 发展（11-30章）：
  - 基地建设+资源争夺
  - 双女主互动+修罗场
  - 危机升级+实力提升

- 高潮（31-45章）：
  - 大型掠夺者入侵
  - 女主1展现实力
  - 女主2被绑架事件
  - 主角爆发+营救成功

- 结局（46-50章）：
  - 基地站稳脚跟
  - 引入新势力（军方）
  - 系统升级（特殊地点签到）
  - 悬念：更大的危机逼近
```

## 三、实战技巧

### 技巧1：开场钩子（黄金三章）

```
第1章：末世降临+激活系统+第一次签到
第2章：囤货展示+初遇女主+初次交锋
第3章：危机爆发+打脸爽点+女主关注

每个场景都要有钩子！不要写铺垫！
```

### 技巧2：爽点叠加

```
单章不要只用一个爽点，要叠加：

示例：
主爽点：歼灭掠夺者
次爽点1：无人机碾压展示
次爽点2：物资收集震撼众人
次爽点3：女主苏媚展现实力
次爽点4：女主林若雪更加依赖
```

### 技巧3：悬念设置

```
每章必须留下悬念钩子：

常见钩子：
- "门外传来了脚步声..."
- "他感觉有人在窥视自己..."
- "系统突然弹出了新的提示..."
- "一个熟悉的声音响起..."
- "他没想到的是，更大的危险已经降临..."
```

### 技巧4：修罗场节奏

```
双女主的修罗场要节奏适中：

- 每5章一次小修罗场
- 每15章一次大修罗场
- 比如同时争夺主角关注/同时展现魅力/同时吃醋
```

### 技巧5：人性考验

```

番茄末世文必须有人性考验：

常见模式：
- 牺牲队友还是救女主？
- 物资分享还是私人占有？
- 接纳陌生人还是封闭基地？
- 复仇还是放过？
```

## 四、AI辅助创作流程

### 第一步：初始化（设置数据库）

```
1. 构建末世世界数据库（参考"技能1"）
2. 设计角色状态模板（参考"技能2"）
3. 建立爽点分类库（参考"技能3"）
```

### 第二步：规划剧情（10章大纲）

```
1. 使用"剧情推进Prompt"设计10章
2. 确保每3章一个小高潮，第10章大反转
3. 标注每章爽点类型
```

### 第三步：逐章生成

```
1. 使用"单章剧情生成Prompt"生成章节
2. AI生成后人工检查逻辑和人设
3. 调整细节，保持流畅
4. 每章至少2个爽点
5. 结尾必须有悬念钩子
```

### 第四步：循环推进

```
1. 每生成10章，更新"世界状态"和"角色状态"
2. 规划下10章
3. 继续生成...
```

## 五、质量检查清单

### 章节检查

```
□ 开场有钩子（3句话内切入冲突）
□ 本章至少2个爽点
□ 结尾有悬念
□ 符合人设逻辑
□ 无明显bug
□ 字数达标（2000字±200）
□ 符合番茄末世文风格
```

### 整体检查

```
□ 世界观一致性
□ 角色成长弧光
□ 爽点密度达标
□ 悬念钩子密度
□ 感情线推进节奏
□ 长线伏笔回收率
```

## 六、效率优化

### 批量生产方法

```
1. 一次性规划50章（10个10章规划）
2. 批量生成10章大纲
3. 每天生成5-10章正文
4. 人工润色+质量检查
5. 目标：日产3万字以上
```

### AI辅助优化

```
1. 用AI生成剧情大纲
2. 用AI生成章节草稿
3. 人工修改润色（关键部分）
4. AI检查逻辑漏洞
```

## 七、番茄末世文套路总结

### 经典套路

```
1. 末世降临前三天开始囤货
2. 系统签到+空间显示
3. 掠夺者/恶霸被打脸
4. 女主们逐渐爱上主角
5. 其他男主/反派想抢女主
6. 系统升级/新功能解锁
7. 发现末世真相
8. 成为一方霸主
9. 建立新势力
10. 大结局：重建秩序
```

### 反套路技巧

```
1. 不要让主角太完美（留缺陷）
2. 女主要有自己的目标/性格
3. 反派要有智商（不能无脑送）
4. 危机要有层次感（递进式）
5. 爽点要多样化（打脸/囤货/修罗场）
```
