# AI自动生成小说剧情系统

> 核心目标：让AI像一个剧情引擎一样持续生成可写的章节，而不是只给零散灵感。

---

## 五大核心模块

### 1. 世界状态 Prompt（World State）

AI必须知道当前世界状态，否则剧情会乱。

#### 模板

```
小说背景：
[填写末世废土/修仙/都市等背景]

世界结构：
- [势力1]
- [势力2]
- [势力3]
- [势力4]
- [势力5]

当前阶段：
[填写当前阶段]

当前区域：
[填写当前区域]
```

#### 示例

```
小说背景：
末世废土世界，人类文明崩溃，怪物横行。

世界结构：
- 安全区联盟
- 掠夺者势力
- 机械城
- 变异荒原
- 系统文明

当前阶段：
废土势力争夺阶段

当前区域：
废弃城市安全区
```

#### 作用

让AI保持世界观一致。

---

### 2. 角色状态 Prompt（Character State）

AI必须知道人物当前情况。

#### 模板

```
主角：[姓名]
身份：[当前身份]
能力：[核心能力]

当前实力：
[等级/战力]

当前资源：
- [资源1]
- [资源2]
- [资源3]

当前目标：
[阶段性目标]
```

#### 主角示例

```
主角：陆沉
身份：前兵王
能力：咸鱼签到系统

当前实力：
A级进化者

当前资源：
- 地下基地
- 无人机军团
- 物资仓库

当前目标：
保护基地发展势力
```

#### 女主示例

```
角色：林若雪
身份：豪门大小姐
能力：资源整合

角色：苏璃
身份：快穿任务者
任务：攻略主角
```

### 3. 爽点调度 Prompt（关键）

控制剧情爽点。

#### 模板

```
本章爽点类型：

1. [打脸爽点/系统奖励/物资装逼/战斗碾压]
2. [打脸爽点/系统奖励/物资装逼/战斗碾压]
3. [打脸爽点/系统奖励/物资装逼/战斗碾压]

AI会围绕这些写剧情。
```

#### 示例

```
本章爽点类型：

1. 打脸爽点
2. 系统奖励
3. 物资装逼
4. 战斗碾压
```

---

### 4. 单章剧情生成 Prompt（最核心）

这个Prompt可以直接生成一章剧情。

#### 模板

```
你是一名男频爽文作者。

根据以下设定写一章小说剧情。

要求：

1. 男频爽文节奏
2. 本章2000字左右
3. 至少包含2个爽点
4. 结尾留悬念

世界背景：
[填写世界状态]

人物状态：
[填写角色状态]

本章冲突：
[填写本章核心冲突]

本章爽点：
[填写爽点类型]

请写出完整剧情。
```

#### 示例

```
你是一名男频爽文作者。

根据以下设定写一章小说剧情。

要求：

1. 男频爽文节奏
2. 本章2000字左右
3. 至少包含2个爽点
4. 结尾留悬念

世界背景：
末世废土世界，人类文明崩溃，怪物横行。
世界结构：安全区联盟、掠夺者势力、机械城、变异荒原、系统文明
当前阶段：废土势力争夺阶段
当前区域：废弃城市安全区

人物状态：
主角：陆沉，前兵王，咸鱼签到系统
当前实力：A级进化者
当前资源：地下基地、无人机军团、物资仓库
当前目标：保护基地发展势力

本章冲突：
掠夺者帮派准备抢夺主角基地物资

本章爽点：
打脸 + 战斗碾压 + 系统奖励

请写出完整剧情。
```

### 5. 剧情推进 Prompt（长线控制）

避免AI乱写。

#### 模板

```
你是小说剧情策划。

根据当前剧情发展设计接下来10章剧情。

要求：

1. 每3章一个小高潮
2. 第10章必须有大反转
3. 必须推进主线

当前剧情：
[填写当前剧情状态]

请设计未来10章剧情。
```

#### 示例

```
你是小说剧情策划。

根据当前剧情发展设计接下来10章剧情。

要求：

1. 每3章一个小高潮
2. 第10章必须有大反转
3. 必须推进主线

当前剧情：
主角建立了地下基地，
掠夺者帮派盯上基地资源，
快穿任务者开始接近主角。

请设计未来10章剧情。
```

## 剧情自动生成流程

### 使用顺序

#### 第一步：生成剧情规划
设计未来10章剧情

#### 第二步：逐章生成剧情
- 生成第1章
- 生成第2章
- 生成第3章

#### 第三步：循环推进
不断更新：
- 世界状态
- 角色状态

AI就能持续写。

```
节奏快
对白多
爽点密集
每章都有冲突
```

## 自动剧情生成公式

AI写小说可以用这个公式：

```
剧情 = 冲突 + 升级 + 爽点 + 悬念
```

#### 示例

```
冲突：
掠夺者抢物资

升级：
敌人数量增加

爽点：
主角召唤无人机军团

悬念：
出现新的系统宿主
```

## 使用建议

1. **初始化阶段**：
   - 构建完整的世界数据库
   - 设计角色状态模板
   - 建立爽点分类库

2. **生成阶段**：
   - 先用"剧情推进Prompt"设计10章大纲
   - 再用"单章剧情生成Prompt"逐章生成
   - 每章生成后更新"世界状态"和"角色状态"

3. **质量控制**：
   - 每章至少2个爽点
   - 结尾必须有悬念
   - 保持男频爽文节奏

4. **效率优化**：
   - 批量生成章节大纲
   - 生成后人工润色
   - 日产3万字以上
