# 男频网文创作器 / Male Webfiction Creator

## 核心功能

基于番茄等平台的实战经验，提供从创意构思到开篇大纲的完整创作指导。涵盖四大脑洞文类型（都市、玄幻、悬疑、科幻）和四步创作法。

## 四步创作法

### Step 1: 一句话概括故事

**公式：**
```
负价值形容词的×主角身份×想要×正价值欲望×而去×动作的故事
```

**示例：**
- 废柴的天才想要出人头地而去成为斗帝的故事
- 被遗弃的医女想要生存必须去陪葬的故事
- 退休的战神想要报恩而去都市中掀起血雨腥风的故事

**要求：**
- ✅ 正价值必须和负价值对立
- ✅ 欲望具象化
- ✅ 设置期待感
- ✅ 测试：问朋友"我有个xxx的故事，你有兴趣听吗？"

---

### Step 2: 构建故事支点（可多选）

#### A. 人物支点 - 角色矛盾

**方法：** 正向期待 + 负价值

**示例：**
- 师者 + 离经叛道/玩世不恭 → 摆烂宗主、学鬼道的儒生
- 退休战神 + 懦懦弱弱 → 反差萌

**引出故事：** 合理化冲突，形成人物小传

#### B. 世界观支点 - 规则冲突

**要求：** 新规则与主角（读者）价值观冲突，引发"为什么？"

**示例：**
- 不能装床帘的校规（学长养猪300斤）
- 必须吃早餐才能存活的世界
- 不能996的世界

**持续碰撞：** 价值观碰撞产生新故事

#### C. 金手指支点

**常见：** 系统、特殊能力、物品

**核心原则：**
- 金手指是工具，主角驱动金手指
- 反向设计：欲望的负价值
  - 想逃离皇朝的王子 + 成帝系统
  - 想赚钱的重生者 + 亏钱系统

#### D. 悬念支点

**适用：** 悬疑类

**方法：** 系统性制造悬念
- 密室死亡游戏、规则怪谈
- 大坑套小坑，坑里还有水，水里还有坑

**关键：** 必须圆回来

#### E. 二次行为（过激行为）

**公式：**
```
一次行为（正常）→ 二次行为（过激）→ 后续事件
```

**示例：**
- 找师傅讨要功法 → 深夜伙同师妹偷功法 → 被吊打/赶出宗门/发现夺舍阵法

#### F. 激励事件（干扰事件）

**定义：** 打破现有局面，迫使选择

**常见：**
- 上门闹事
- 天降遗产（100亿）
- 奖励/惩罚

---

### Step 3: 切入事件（开篇七要素）

**最佳选择：** 激励事件或过激行为

**开篇必备信息：**
1. ✅ 展示主角处境和对现状的不满
2. ✅ 给读者喜欢主人公的理由
3. ✅ 主人公遭受不公平的伤害
4. ✅ 主人公面临危险或已身处危险
5. ✅ 金手指出现，事情出现转机
6. ✅ 建立短期追求的目标
7. ✅ 一个引人致胜的情节钩子

**⚠️ 重要：**
- 不必按固定顺序
- 不要生搬硬套
- 学习爆款作品
- 用新眼光看文学作品

---

### Step 4: 大纲结构（三幕式 + 节拍器）

#### 理解爽点

**爽点本质：** 满足读者情绪需求

**类型：**
- 历经艰辛终成眷属的爱情
- 三千里逃亡后的劫后余生
- 冥思苦想解开数学题
- 黑暗中探索到的一道光

**⚠️ 不只是装逼打脸**

#### 三幕式结构

**传统：** 建制 → 对抗 → 结束
**四幕：** 建制 → 推进 → 转折 → 结束
**简化：** 起、承、转、合

#### 应用方式

**长时间线：** 三幕式主要脉络
**短时间线：** 情绪拉扯（期待-满足）填充

#### 二级结构

对切入事件用三幕式处理：
```
设置期待 → 冲突升级 → 满足期待（爽点）→ 设置新期待
```

#### 情绪曲线

```
         上升期（满足期待/爽点）
        /\
       /  \
      /    \  下降期（冲突/意外/担忧）
     /      \
    /        \
   /          \
  /            \
 /______________\
```

**操作要点：**
- 曲线起伏越大 = 冲突越剧烈 = 读者情绪波动越大
- 上升期：打倒坏蛋、完成成就、获得宝藏
- 下降期：发生冲突、意外、担忧（不符合期待=设置期待）
- 不断反复：期待→满足=情绪拉扯

#### 反同质化

**避免：** 一直同一种模式的爽点

**建议：**
- 设置不同期待，满足不同期待
- 给读者新鲜感
- 可以多条曲线、多个起伏
- 可自定义节拍器

**⚠️ 核心：** 一切为内容服务，不要生搬硬套！

#### 大纲构建建议

**首卷：**
- 15-20万字
- 高潮放10万字后
- 不低于10万字（完读数据重要）

**后续：** 慢慢构筑，可随时修改

## 脑洞文四大分类

### 都市脑洞

**特点：** 都市背景 + 想象力 + 金手指 + 快节奏爽文

**常见题材：**
- 神豪类（致富金手指）
- 直播类（观察观众、收获怨念值）
- 文娱类（编剧/导演/歌手职业）
- 美食/宠物/校花类

**补充：**
- 多维度成长：爱情、事业、财富
- 灵感：时事新闻、短视频热梗
- 禁止：攻略/后宫/躺平

---

### 玄幻脑洞

**特点：** 玄幻世界 + 系统金手指

**常见题材：**
- 无敌签到文（签到得奖励）
- 万倍返还文（馈他人获万倍）
- 长生苟道流（无穷寿命、稳健修仙）
- 宗门建设文（落魄宗门种田）
- 收徒就变强（收徒修为提高）

**建议：**
- 新手：吃透成熟套路
- 基础好：套路中创新开拓
- 多下功夫：人物、世界、修炼体系

---

### 悬疑脑洞

**特点：** 平行世界 + 诡异鬼怪 + 系统金手指

**常见题材：**
- 惊悚游戏（高死亡率游戏，靠智慧通关）
- 规则怪谈（死亡规则 + 逻辑推理）
- 诡异复苏（灵气鬼怪同时复苏，人类vs鬼怪）
- 恐怖末世（鬼怪复苏引发末日，重生/先知先觉）

**重点：** 金手指新颖性和趣味性

---

### 科幻

**特点：** 未来世界 + 科技想象 + 异能变异

**常见题材：**
- 末世题材（末世冲击 + 人性改变 + 新力量体系）
- 黑科技题材（当代背景 + 未来高科技）
- 星际题材（宇宙星际 + 玄幻高武/机甲）

## 书名技巧

**三大作用：**
1. 识别
2. 设置期待感
3. 筛选读者

**要求：**
- ✅ 句式生动有趣、不刻板
- ✅ 接地气、有反差效果
- ✅ 概括核心脑洞、高光情节
- ✅ 用词准确清楚，不生造词汇

**创作步骤：**
1. 明确最核心/最新颖/最有趣的设定或名场面
2. 用一两句话概括
3. 替换关键词（时代感→新鲜、模糊→明确）
4. 调整句式（流行、一目了然）
5. 浓缩精炼（≤15字，含标点）

---

## 开篇技巧

**要求：**
- ✅ 快速进入剧情（不写长背景设定）
- ✅ 主线清晰明确（开篇就告知故事脉络）
- ✅ 可以用紧迫性、矛盾感事件开头
- ✅ 适当铺设悬念或制造反转
- ⚠️ 避免开篇剧透最终结局
