# 男频网文创作指南

## 核心创作流程

### 第一步：一句话概括故事

**公式：**
```
负价值形容词的×主角身份×想要×正价值欲望×而去×动作的故事
```

**示例：**
- 废柴的天才想要出人头地而去成为斗帝的故事
- 被遗弃的医女想要生存必须去陪葬的故事
- 退休的战神想要报恩而去都市中掀起血雨腥风的故事

**核心要点：**
1. 正价值必须和负价值相对立
2. 欲望最好具象化
3. 设置期待感：正负价值的碰撞
4. 测试方法：问朋友"我有个xxx的故事，你有兴趣听一下吗？"

---

### 第二步：构建故事支点

**什么是故事支点？**
能通过一个元素引出一个或多个故事的支撑点。都可以作为书名使用。

#### 1. 人物支点 - 角色矛盾

**方法：** 在角色的正向期待上加上负价值
- 师者（正向：传道授业解惑）+ 离经叛道、玩世不恭（负价值）
- 摆烂宗主、学鬼道的儒生

**引出故事：** 合理化这个冲突，形成人物小传或切入点

#### 2. 世界观支点 - 规则冲突

**要求：**
- 有一条新规则，与主角（读者）价值观冲突
- 引发"为什么？"的疑问

**示例：**
- 不能装床帘的校规（因为学长在宿舍养猪养到300斤）
- 必须吃早餐才能存活的世界
- 不能996的世界

**持续碰撞：** 世界观与主角价值观的不断碰撞产生新故事

#### 3. 金手指支点

**常见金手指：**
- 系统（发任务、发奖励）
- 其他类型（获得过程、获得后影响）

**核心原则：**
- 金手指是工具，主角驱动金手指，不能本末倒置
- 反向设计：欲望的负价值
  - 想逃离皇朝的王子 + 成帝系统
  - 想赚钱的重生者 + 亏钱系统

#### 4. 悬念支点

**适用：** 悬疑类小说

**方法：** 系统性制造悬念
- 《十日终焉》：密室死亡游戏开局
- 一头懵 + 大坑套小坑 + 坑里还有水 + 水里还有坑

**关键：** 必须圆回来，不能是事故

#### 5. 二次行为（过激行为）

**定义：** 主角过于激进引发的事件

**公式：**
```
一次行为（正常）→ 二次行为（过激）→ 后续事件
```

**示例：**
- 找师傅讨要功法（一次）
- 深夜伙同师妹偷功法（二次）
- 结果：吊起来打 / 赶出宗门 / 发现夺舍阵法

#### 6. 激励事件（干扰事件）

**定义：** 打破现有局面，迫使主角选择

**常见类型：**
- 上门闹事
- 天降遗产（比如100亿）
- 奖励/惩罚

**作用：** 激发主角的欲望和选择，改变命运

---

### 第三步：切入事件（开篇七要素）

**最佳选择：** 激励事件或过激行为

**开篇必备信息（借鉴《故事策略》）：**

1. ✅ 展示主角处境和对现状的不满
2. ✅ 给读者喜欢主人公的理由
3. ✅ 主人公遭受不公平的伤害
4. ✅ 主人公面临危险或已身处危险
5. ✅ 金手指出现，事情出现转机
6. ✅ 建立短期追求的目标
7. ✅ 一个引人致胜的情节钩子

**男频特点：** 以上信息要尽早出现

**⚠️ 重要：**
- 不必按固定顺序
- 不要生搬硬套
- 学习爆款作品如何运用这些方法
- 用新眼光看文学作品，解锁独特理解

---

### 第四步：大纲 - 三幕式结构/节拍器

#### 理解爽点

**爽点 ≠ 装逼打脸**

**爽点本质：** 满足读者情绪需求

**爽点类型：**
- 历经艰辛终成眷属的爱情
- 三千里逃亡后的劫后余生
- 冥思苦想解开数学题
- 黑暗中探索到的一道光

#### 三幕式结构

**传统三幕式：**
- 建制（Act I）
- 对抗（Act II）
- 结束（Act III）

**也可以是四幕式：**
- 建制
- 推进（对抗上）
- 转折（对抗下）
- 结束

**简化理解：** 起、承、转、合

#### 应用方式

**长时间线：** 用三幕式作为主要脉络
**短时间线：** 用情绪拉扯（期待-满足）填充

#### 二级结构

对切入事件也可以用三幕式处理：
```
设置期待 → 冲突升级 → 满足期待（爽点）→ 设置新期待
```

#### 情绪曲线

```
         上升期（满足期待/爽点）
        /\
       /  \
      /    \  下降期（冲突/意外/担忧）
     /      \
    /        \
   /          \
  /            \
 /______________\
```

**操作要点：**
- 曲线起伏越大 = 冲突越剧烈 = 读者情绪波动越大
- 上升期：打倒坏蛋、完成成就、获得宝藏等
- 下降期：发生冲突、意外、担忧（不符合读者期待=设置期待）
- 不断反复：设置期待→满足期待=情绪拉扯

#### 反同质化

**避免：** 一直是同一种模式的爽点（如装逼打脸）

**建议：**
- 设置不同的期待，满足不同的期待
- 给读者新鲜感
- 可以多条曲线、多个起伏
- 可以自定义节拍器（如好莱坞斯奈德节拍器）

**⚠️ 核心：** 一切为内容服务，不要生搬硬套！

#### 大纲构建建议

**首卷聚焦：**
- 先构建第一卷（15-20万字）
- 不低于10万字（番茄完读数据重要）
- 高潮情节放在10万字之后

**后续大纲：** 慢慢构筑，不影响大局即可

**灵活性：** 大纲可以随时修改，有更好内容就替换

## 脑洞文四大分类

### 1. 都市脑洞

**概述：** 都市背景 + 想象力 + 金手指（系统/异能/身体异变）+ 快节奏爽文

**常见题材：**
- **神豪类：** 致富类金手指为主线
- **直播类：** 观察观众厄运值、收获怨念值等异能
- **文娱类：** 编剧/导演/歌手职业 + 职业优势金手指
- **美食类、宠物类、校花类：** 对应元素为主线

**补充说明：**
- 鼓励多维度发散思维
- 重视期待感、人物塑造、成长体系
- 多维度成长：爱情、事业、财富
- 灵感来源：时事新闻、短视频热梗

**注意事项：**
- 非都市脑洞类不参与评选
- 修真/修炼/高武主线不在评选范围
- 禁止攻略/后宫/躺平等类型
- 文娱直播类规避版权风险和政治影射

---

### 2. 玄幻脑洞

**概述：** 玄幻世界 + 系统等金手指

**常见题材：**
- **无敌签到文：** 签到获得奖励（功法、法宝、境界提升）
- **万倍返还文：** 馈赠他人获得万倍返还
- **长生苟道流：** 无穷寿命、稳健修仙、坐看沉浮
- **宗门建设文：** 落魄宗门种田经营
- **收徒就变强：** 收徒弟修为提高，特殊徒弟触发奖励

**补充说明：**
- **新手：** 吃透成熟题材套路（如无敌签到文）
- **基础好：** 在成熟套路上创新开拓新脑洞
  - 如宗门建设 = 无敌文变种
- **质感和卖点：** 多下功夫在人物、世界观、修炼体系
- **轻小说方向：** "玩儿梗""卖人设"为重点

---

### 3. 悬疑脑洞

**概述：** 平行世界 + 诡异鬼怪 + 系统金手指

**常见题材：**
- **惊悚游戏：** 选中玩家参与高死亡率游戏（青山精神病院、死亡学校等），靠智慧和金手指通关
- **规则怪谈：** 死亡副本 + 逻辑严密规则（包含假规则），重点推理解谜
- **诡异复苏：** 灵气和鬼怪同时复苏，人类vs鬼怪阵营战斗
- **恐怖末世：** 鬼怪复苏过于猛烈，人类崩溃，主角重生/先知先觉

**重点创新：** 金手指的新颖性和趣味性

---

### 4. 科幻

**概述：** 未来世界 + 科技想象 + 异能变异

**常见题材：**
- **末世题材：** 末世对社会冲击 + 人际关系人性改变 + 新力量体系（异能变异等），重生/囤物资/异能天赋
- **黑科技题材：** 当代背景 + 发展未来高科技，签到/科技树系统
- **星际题材：** 宇宙星际社会 + 玄幻高武/机甲黑科技，宏大舞台 + 多样副本

---

## 创新思路

**从传统套路中：**
- 反套路
- 加入新鲜元素

**灵感来源：**
- 抖音短视频
- 热门综艺等媒介平台

---

## 书名技巧

**三大作用：**
1. 识别
2. 设置期待感（吸引阅读兴趣）
3. 筛选读者

**要求：**
- ✅ 句式生动有趣、不刻板
- ✅ 接地气、有反差效果
- ✅ 概括核心脑洞、高光情节
- ✅ 用词准确清楚，不生造词汇

**创作步骤：**
1. 明确最核心/最新颖/最有趣的设定或名场面
2. 用一两句话概括
3. 替换关键词（时代感→新鲜、模糊→明确）
   - "肿么破"→"人麻了"
   - "佛系"→"开摆""咸鱼"
   - "美女"→"高冷校花""病娇女帝"
4. 调整句式（流行、一目了然）
5. 浓缩精炼（≤15字，含标点）

---

## 开篇技巧

**要求：**
- ✅ 快速进入剧情（不写长背景设定）
- ✅ 主线清晰明确（开篇就告知故事脉络）
- ✅ 可以用紧迫性、矛盾感事件开头（抓住目光）
- ✅ 适当铺设悬念或制造反转
- ⚠️ 避免开篇剧透最终结局

---

## 核心方法论总结

**四步法：**
1. 一句话概括（正负价值对立）
2. 构建支点（人物/世界/金手指/悬念/事件）
3. 切入事件（开篇七要素）
4. 大纲结构（三幕式 + 节拍器）

**理解爽点：** 满足情绪需求，不只是装逼打脸
**情绪拉扯：** 期待-满足-期待循环
**大纲灵活：** 先完成首卷，可随时修改
**创新方向：** 反套路 + 新元素 + 媒介灵感

**书名开篇：** 设置期待 + 筛选读者 + 快速入戏

---

**实战建议：**
- 新手先模仿成熟套路
- 基础好则在套路中创新
- 多维度成长（情感、事业、财富）
- 人物/世界观/体系下功夫
- 一切为内容服务，别生搬硬套
