# 故事分析器 / Story Analyzer

## 核心功能

基于拆稿数据的故事分析方法论：

### 1. 结构分析法

**完整拆解框架：**

```
故事分析表（基于拆稿数据）

基本信息：
├── 篇名：_______
├── 总字数：_______
├── 类型：_______
├── 核心冲突：_______
└── 主要人物：_______

分段分析：
分段 | 字数 | 故事进展 | 地点/人物 | 事件/冲突 | 学习之处
-----|------|----------|-----------|-----------|-----------
1    |      |          |           |           |
2    |      |          |           |           |
...

总结分析：
├── 结构特点：_______
├── 节奏规律：_______

├── 人物成长：_______
├── 反转设计：_______
```

**结构分析维度：**

```
维度1：故事进展模式
├── 开篇方式：
│   ├── 危机式：立即陷入困境
│   ├── 悬念式：反常现象
│   ├── 对比式：现状vs理想
│   └── 日常式：平静生活被打破
├── 发展方式：
│   ├── 递进式：逐步升级
│   ├── 循环式：重复中变化
│   ├── 并行式：多线推进
│   └── 闪回式：过去现在交织
├── 高潮方式：
│   ├── 爆发式：情绪和冲突顶点
│   ├── 揭秘式：真相大白
│   ├── 选择式：关键决定
│   └── 牺牲式：为他人牺牲
└── 结局方式：
    ├── 完全解决：所有问题解决
    ├── 部分解决：主要问题解决
    ├── 开放式：引发思考
    └── 悲剧式：失败但有意义

├── 总冲突次数：_______

├── 冲突间隔：平均_______字

├── 反转次数：_______
├── 反转位置：
│   ├── 第一次：_____%处
│   ├── 第二次：_____%处
│   └── 最后一次：_____%处
├── 反转类型：
│   ├── 信息类：_______
│   ├── 时间类：_______
```

### 3. 模式识别法

**常见故事模式：**

```
模式A：时间循环模式
识别特征：
├── 主角经历重复事件
├── 每次循环有变化
├── 逐步接近真相
└── 最后找到突破方法

结构规律：
├── 循环0：初始状态
├── 循环1-2：探索阶段
├── 循环3-4：深化阶段
└── 循环5：突破阶段

关键要素：
├── 循环触发条件：_______
├── 每次循环增量信息：_______
├── 主角成长路径：_______
└── 突破关键：_______

案例：《人脸解锁失败》
├── 循环次数：5次
├── 每次增量：外婆爱、真相、勇气
├── 成长路径：恐惧→面对→牺牲
└── 突破关键：理解和爱

模式B：复仇成长模式
识别特征：
├── 初始伤害确立动机
├── 隐忍准备积累能力
├── 逐步反击小试牛刀
└── 全面爆发大结局

结构规律：
├── 开篇：伤害与觉醒（15-20%）
├── 发展：隐忍与准备（25-30%）
├── 反击：小试牛刀（20-25%）
├── 高潮：全面对决（25-30%）
└── 结局：升华与新生（5-10%）

关键要素：
├── 复仇动机：_______
├── 准备过程：_______
├── 反击节点：_______
└── 情感线：_______

案例：《南南以星》
├── 动机：被母亲抛弃、被撞人
├── 准备：收集证据、男主配合
├── 反击：直播揭露、复仇成功
└── 情感：双向奔赴、真爱救赎

模式C：谜题揭秘模式
识别特征：
├── 开篇设置谜团
├── 逐步收集线索
├── 多次假象误导
└── 最后真相揭露

结构规律：
├── 开篇：设置谜团（15-20%）
├── 发展：调查与误导（35-40%）
├── 转折：真相初现（20-25%）
└── 高潮：完整揭秘（20-25%）

关键要素：
├── 核心谜题：_______
├── 线索设计：_______
├── 红鲱鱼：_______
└── 多层反转：_______

案例：《活在真空里》
├── 谜题：学弟为何杀人
├── 线索：视频证据、工地尸体
├── 红鲱鱼：买凶杀人、嘱托杀人
└── 真相：为寻找哥哥遗体

模式D：救赎和解模式
识别特征：
├── 主角有过去错误
├── 遭遇相关事件
├── 逐步面对过去

结构规律：
```

### 4. 对比分析法

**多作品对比框架：**

```

├── 字数对比
├── 结构对比
├── 冲突对比
├── 人物对比

-----|-------|-------|-------|----------
字数 |       |       |       |
结构 |       |       |       |
冲突 |       |       |       |
...

发现规律：
├── 字数规律：_______
├── 结构规律：_______
├── 冲突规律：_______
├── 人物规律：_______
└── 技巧规律：_______
```

**对比分析案例：**

```
对比三部拆稿作品：

维度1：字数和节奏
├── 《人脸解锁失败》：11,708字
│   └── 节奏：每个循环一个波峰
├── 《活在真空里》：19,911字
│   └── 节奏：持续加速，反转密集
└── 《南南以星》：11,436字
    └── 节奏：起伏有致，爽点密集

规律：1-2万字适合短篇，节奏要有变化

维度2：冲突设计
├── 《人脸解锁失败》
│   └── 生存冲突→道德冲突→情感冲突
├── 《活在真空里》
│   └── 法律冲突→道德冲突→社会冲突
└── 《南南以星》
    └── 身份冲突→情感冲突→复仇冲突

规律：多维度冲突叠加，层次丰富

维度3：反转设计
├── 《人脸解锁失败》
│   └── 5次循环，每次都是小反转
├── 《活在真空里》
│   └── 7-8层反转，层层递进
└── 《南南以星》
    └── 3次大反转（身份、真相、关系）

规律：反转密集但要有逻辑，符合故事类型
```

## 分析质量标准

**分析完整性：**

```
□ 覆盖所有关注领域？
□ 信息准确无误？
□ 逻辑清晰连贯？
□ 细节充分具体？
□ 规律总结到位？
```

**分析实用性：**

```
□ 技巧可复用？
□ 模板可操作？
□ 建议具体明确？
□ 有实例支撑？
□ 可直接应用？
```

**分析深度：**

```
□ 不止表面总结？
□ 深入挖掘规律？
□ 发现隐藏模式？
□ 提供新视角？
□ 有独到见解？
```
