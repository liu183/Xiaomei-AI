# 故事结构设计 / Story Structure Designer

## 核心结构模板

基于拆稿数据分析的短篇小说结构规律：

### 1. 三幕式结构（经典/Classic）

**适用范围：** 世情、悬疑、情感类
**字数分配：** 1.5-2万字

```
第一幕：建立困境（25-30%，约4000-6000字）
├── 开篇（500-1000字）
│   ├── 引入主角现状
│   ├── 建立核心关系
│   └── 抛出初始悬念
├── 激励事件（1000-1500字）
│   ├── 打破平静生活
│   ├── 明确核心冲突
│   └── 确立故事目标
└── 第一次危机（2000-3000字）
    ├── 主角尝试解决问题
    ├── 遭遇第一次失败
    └── 陷入更深的困境

第二幕：升级冲突（40-50%，约7000-9000字）
├── 试炼与成长（2500-3500字）
    │   ├── 主角多次尝试
    │   ├── 能力/认知提升
    │   └── 小的胜利和挫折
├── 中点反转（2000-3000字）
    │   ├── 重大真相揭露
    │   ├── 局势发生根本变化
    │   └── 目标/动机发生转变
└── 至暗时刻（2000-3000字）
        ├── 主角遭遇最大打击
        ├── 看似无解的困境
        └── 必须做出艰难选择

第三幕：解决高潮（25-30%，约4000-6000字）
├── 最后的尝试（1500-2500字）
│   ├── 主角找到破局关键
│   ├── 带着成长再次面对
│   └── 与反派/困境对决
├── 高潮对决（2000-3000字）
│   ├── 爆发所有冲突
│   ├── 展现主角真正的改变
│   └── 决定胜负的关键时刻
└── 结局（1000-1500字）
    ├── 处理善后
    ├── 展现变化和成长
    └── 留下余韵/思考
```

**案例分析：《人脸解锁失败》结构分解**

总字数：11,708字

```
第一幕：陷入循环困境（约3500字，30%）
├── 开篇危机（1090字）
│   ├── 被手机提示音吵醒
│   ├── 发现有人闯入
│   ├── 反派王翠兰出现
│   └── 外婆处于危险中
├── 第一次循环失败（826字）
│   ├── 尝试保护外婆失败
│   ├── 发现新问题（手机没电）
│   └── 外婆和主角双亡
└── 第二次循环失败（1618字）
    ├── 弥补上次漏洞（拔钥匙）
    ├── 遭遇新障碍（王翠兰从阳台进入）
    ├── 求助失败（保安是假冒的）
    └── 外婆再次牺牲

第二幕：真相逐步揭露（约4700字，40%）
├── 第三次循环（1881字）
│   ├── 揭露王翠兰身份（性工作者）
│   ├── 揭露动机（为妹妹复仇）
│   ├── 主角想起自己是记者
│   └── 了解事件真相
├── 回忆与转折（1498字）
│   ├── 主角选择放弃报道
│   ├── 王翠兰绝望自杀
│   ├── 主角自杀试图回到循环
│   └── 确立拯救外婆的目标
└── 第四次循环（1346字）
    ├── 主动对峙王翠兰
    ├── 道歉被拒绝
    ├── 外婆再次挡刀
    └── 得知外婆非亲孙女但深爱她

第三幕：最终解决（约3500字，30%）
├── 主角成长（1811字）
│   ├── 回忆外婆的付出
│   ├── 下定决心救外婆
│   └── 克服对死亡的恐惧
├── 第五次循环（846字）
│   ├── 直接对峙
│   ├── 提供解决方案（报道真相）
│   ├── 外婆协助劝说
│   └── 成功化解危机
└── 大结局
    ├── 外婆活下来
    ├── 主角发布真相
    └── 王翠兰得到救赎
```

**结构规律总结：**
1. **循环递进**：每次循环解决旧问题，遇到新障碍
2. **信息分层**：逐步揭露反派背景和动机
3. **情感升级**：从恐惧逃避→勇敢面对→主动拯救
4. **至暗时刻**：第3-4次循环时主角最绝望

### 2. 时间循环结构（Time Loop）

**适用范围：** 悬疑、惊悚、救赎类
**核心要素：**
- 明确的循环触发条件
- 每次循环的增量信息
- 主角的成长和策略进化
- 最终突破循环的关键

```
结构模板：
┌─────────────────────────────────────┐
│ 循环0：初始状态                     │
│ - 主角陷入困境                      │
│ - 不了解循环规则                    │
│ - 第一轮死亡/失败                   │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│ 循环1-2：探索阶段                   │
│ - 发现循环规律                      │
│ - 尝试不同策略                      │
│ - 收集关键信息                      │
│ - 仍然失败但有进展                  │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│ 循环3-4：深化阶段                   │
│ - 了解更多背景                      │
│ - 接近真相但仍有盲点                │
│ - 遭遇最大挫折（至暗时刻）          │
│ - 似乎无解                          │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│ 循环5：突破阶段                     │
│ - 关键顿悟（情感/逻辑）             │
│ - 找到破局关键                      │
│ - 成功打破循环                      │
└─────────────────────────────────────┘

字数分配建议：
- 每个循环：1500-2500字
- 总循环次数：4-6次
- 重点循环详细写，其他循环可简略
```

**写作技巧：**
1. **避免重复感**：每次循环要有新的信息或尝试
2. **递进式揭示**：反派动机、人物关系分层揭露
3. **情感弧光**：主角从被动→主动，从恐惧→勇敢
4. **节奏变化**：前面循环快，后面循环慢且详细

### 3. 谜题揭秘结构（Mystery Reveal）

**适用范围：** 悬疑、推理、心理类
**核心要素：**
- 开篇设置谜团
- 线索的埋设和误导
- 多重假象
- 逐层剥茧

```
结构模板：
┌─────────────────────────────────────┐
│ 开篇：设置谜团（15-20%）            │
│ - 反常事件发生                      │
│ - 建立核心疑问                      │
│ - 引入多个可疑人物                  │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│ 发展：调查与误导（35-40%）          │
│ - 收集线索（真假混杂）              │
│ - 提出假说（被推翻）                │
│ - 红鲱鱼（误导读者）                │
│ - 小的突破和新的疑问                │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│ 转折：真相初现（20-25%）            │
│ - 关键证据出现                      │
│ - 推翻之前的假设                    │
│ - 局势发生根本变化                  │
│ - 揭露部分真相                      │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│ 高潮：完整揭秘（20-25%）            │
│ - 所有线索串联                      │
│ - 真相完全揭露                      │
│ - 动机解释                          │
│ - 最终反转                          │
└─────────────────────────────────────┘

案例：《活在真空里》结构分析
总字数：19,911字

开篇谜团（1400字）
├── 引用名言："走投无路时还有犯罪这条路"
├── 学弟报警后杀人（反常）
├── 因推搡就要置人于死地（不合理）
└── 学弟放弃挣扎，接受死刑（有隐情）

调查误导（9000字）
├── 一审死刑
├── 学弟翻供：买凶杀人（假说1）
├── 翻供失败，仍是死刑
├── 学弟再次翻供：嘱托杀人（假说2）
├── 被害人视频证据出现
├── 主角发现被欺骗
└── 四次庭审，层层反转

真相初现（5000字）
├── 学弟讲述完整故事
├── 哥哥失踪，工地掩盖真相
├── 警察不立案，媒体不发声
├── 与被害人合谋闹大案件
└── 一切都是为了找到哥哥遗体

最终真相（4500字）
├── 成功迫使工地找到尸体
├── 被害人系自杀
├── 学弟只判2年
├── 经理招供但疑点重重
└── 细思恐极的暗示
```

**谜题设计技巧：**
1. **信息控制**：不要一次给完线索
2. **红鲱鱼**：合理但错误的推理路径
3. **误导性揭示**：看似真相，实为表象
4. **多重反转**：一个真相背后还有真相
5. **伏笔回收**：开篇的细节在结尾才重要

### 4. 复仇成长结构（Revenge & Growth）

**适用范围：** 大女主、复仇打脸、救赎类
**核心要素：**
- 初始伤害（确立复仇动机）
- 隐忍准备（能力积累）
- 逐步反击（小胜利）
- 全面爆发（高潮打脸）
- 情感升华（获得真爱/自我救赎）

```
结构模板：
┌─────────────────────────────────────┐
│ 开篇：伤害与觉醒（15-20%）          │
│ - 主角遭遇背叛/伤害                │
│ - 确立复仇对象                      │
│ - 意识到自己的不足                  │
│ - 下定决心改变                      │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│ 发展：隐忍与准备（25-30%）          │
│ - 表面示弱，暗中准备                │
│ - 收集证据和弱点                    │
│ - 获得盟友支持                      │
│ - 能力提升（财富/权势/技能）        │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│ 反击：小试牛刀（20-25%）            │
│ - 初步反击计划                      │
│ - 小的胜利                          │
│ - 引起反派警觉                      │
│ - 主角身份/实力部分揭露             │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│ 高潮：全面对决（25-30%）            │
│ - 最终复仇计划展开                  │
│ - 多线并进                          │
│ - 反派的绝望                        │
│ - 完美的打脸                        │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│ 结局：升华与新生（5-10%）           │
│ - 复仇成功但代价                    │
│ - 获得真爱/真情                    │
│ - 重新定义自我                      │
│ - 开启新生活                        │
└─────────────────────────────────────┘

案例：《南南以星》结构分析
总字数：11,436字

开篇：被抛弃与相遇（1200字）
├── 被母亲抛弃，被人贩子拐走
├── 多年后成为首富第十任女友
├── 全网等待她被甩
└── 悬念：她会打破7天分手魔咒吗？

发展：隐忍与收集（4500字）
├── 表面只想搞钱（降低戒心）
├── 与前任们成为朋友
├── 发现自己是白月光替身
├── 女二挑衅，暗中收集证据
├── 男主配合演戏
└── 等待最佳时机

反击：借机打脸（3800字）
├── 女二找人报复
├── 女主直播揭露女二肇事逃逸
├── 女主战斗力爆表
├── 女二家破产
├── 亲妈出现道德绑架
└── 拒绝认亲，"嫌钱脏"

高潮：身份全揭露（1200字）
├── 男主一直知道真相
├── 男主小时候也被拐卖
├── 女主曾帮助男主度过难关
├── 男主一直在寻找女主
└── 双向奔赴，感情升华

结局：大团圆
├── 复仇成功
├── 获得真爱
├── 养母清醒
└── 怀孕生子
```

**复仇文技巧：**
1. **爽点设计**：打脸要有层次感
2. **智商在线**：主角和反派都要有智商
3. **情感线**：复仇+爱情双线并行
4. **反转**：身份、能力、关系不断反转
5. **节奏**：压抑→释放，循环往复

## 通用结构原则

### 分段字数规律

基于拆稿数据的统计：

```
超短段落：200-500字
- 快速切换场景
- 密集的信息输出
- 制造紧张感

短段落：500-800字
- 单个事件或冲突
- 一个小转折

中段落：800-1500字
- 完整场景
- 人物对话推进
- 情感铺垫

长段落：1500-2500字
- 重要情节
- 情感高潮
- 复杂场景描写
```

### 故事进展标记

```
常用故事进展标签：
- 开篇 / 开局
- 陷入危机 / 陷入困境
- 开始解谜 / 探索
- 第一次尝试 / 第一次循环
- 遭遇阻碍 / 反击
- 中点转折 / 重大揭示
- 至暗时刻 / 绝望
- 转机 / 顿悟
- 最后的对决 / 高潮
- 结局 / 真相大白
- 番外 / 后续
```

### 冲突密度控制

```
短篇冲突密度（1.5-2万字）：

开篇冲突（前3000字）
├── 1个主冲突（必须）
├── 2-3个次冲突
└── 悬念钩子

发展冲突（3000-12000字）
├── 每2000字一个转折点
├── 每3000字一个强冲突
├── 每5000字一个中点高潮
└── 至少3-5个不同层级的冲突

高潮冲突（12000-18000字）
├── 汇集所有线索
├── 多线并进
├── 情绪爆发点
└── 终极对决
```

## 使用指南

**Step 1: 选择结构类型**
根据故事核心选择合适模板

**Step 2: 确定字数分配**
按百分比计算各部分字数

**Step 3: 标注关键节点**
在结构中标注：
- 冲突点
- 转折点
- 信息揭露点
- 情绪高潮点

**Step 4: 填充具体内容**
为每个节点设计具体情节

**Step 5: 调整节奏**
根据实际需要调整字数分配
