## 核心设定（确定版）

### 1. 主角设定
**方案A：废柴穿越型**

- **现代身份：** 林小北，25岁，外卖小哥
- **性格：** 废柴但嘴贱，有点小聪明，关键时刻不掉链子，内心善良
- **现代背景：** 混吃等死，生活窘迫，单身狗一枚
- **被选中原因：** 系统随机抽取，纯粹运气（倒霉运→好运转折）

---

### 2. 系统设定
**方案A：直接奖励型 + 预知未来能力**

**核心机制：**
- 每成功拯救一个美女，直接获得强力奖励
- 奖励可以带回现实：金钱、房产、能力等
- 失败惩罚：现代生活变差或扣除奖励

**特殊能力：预知未来**
- 系统给予林小北的能力：可以看到美女们的历史命运和即将发生的悲剧
- 命运轨迹可视化：脑海中可以看到"未来的画面"
- 关键事件预警：系统会在危机前给出警告
- **只给预警，不给方法：** 系统只告诉你即将发生什么，不告诉你如何改变
- 迫使主角思考和决策，不能完全依赖系统

**奖励示例：**
- 初级奖励：100万现金
- 中级奖励：一线城市房产
- 高级奖励：现代能力（超强记忆力、格斗技能、语言天赋）

**任务机制：**
- 发布拯救目标、时间限制、关键节点
- 预警即将发生的危机（时间节点、事件内容）
- 实时提示和帮助（有限度）
- 根据拯救质量给予不同等级奖励

- 主要矛盾：潘金莲即将被迫嫁给武大郎→被设计陷害→被迫杀人
