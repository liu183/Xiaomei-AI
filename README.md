# 共享资源

本目录包含所有写作项目共享的资源、配置和工具。

## 📁 目录结构

### openclaw/
OpenClaw AI 助手的配置文件，定义了人设、能力和工作方式。

- **SOUL.md** - 核心人设和性格定义
- **IDENTITY.md** - 身份信息
- **USER.md** - 用户信息
- **HEARTBEAT.md** - 日常任务和工作流
- **AGENTS.md** - Agent 工作空间说明
- **TOOLS.md** - 可用工具清单

### skills/
OpenClaw 技能模块，可以跨项目使用的专业能力。

### docs/
共享文档、脚本和参考资料。

### templates/
写作模板，包括大纲模板、角色档案模板等。

### assets/
共享素材，包括图片、参考文档等。

## 🔧 使用方式

这些资源可以被所有项目引用和使用。在需要时，可以通过相对路径或软链接访问。
